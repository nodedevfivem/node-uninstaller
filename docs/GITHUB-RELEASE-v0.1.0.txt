RELEASE TITLE: NODE Uninstaller v0.1.0 — Windows Foundation (Installer Pipeline Repair)
RELEASE DESCRIPTION:
NODE Uninstaller v0.1.0 is our read-only Windows application inventory foundation. It includes the official NODE Development logo and dark red/cyan WPF interface, desktop-application inventory, current-user Microsoft Store package detection, search, filters, details, and safe folder/navigation actions.

This revision incorporates the CS0176 XAML event-handler fix and repairs the GitHub Actions installer build pipeline: NSIS now resolves repository paths correctly, uses a compatible installer icon, and reports packaging diagnostics on failure. Modern checkout and .NET setup actions reduce obsolete Node.js runtime warnings.

IMPORTANT: This release is source-only until GitHub Actions confirms a successful Windows build and produces installable artifacts. No application-removal, leftover-deletion, forced-uninstall, batch removal, or Hunter Mode functionality is enabled yet.
