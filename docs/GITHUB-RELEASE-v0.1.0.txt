RELEASE TITLE: NODE Uninstaller v0.1.0 — Foundation & Installed Apps Preview

RELEASE DESCRIPTION:
NODE Uninstaller — Clean Removal. Complete Control.
Developed by NODE Development.

This is our first Windows foundation release. It introduces the branded dark interface and a read-only installed application manager.

WHAT'S INCLUDED
- Official NODE Uninstaller red/cyan logo integrated into the Windows app.
- Modern dark WPF dashboard with custom title bar, sidebar and app details.
- Discovery of registered desktop applications (HKLM/HKCU, 32-bit and 64-bit views).
- Discovery of current-user Microsoft Store main packages via Windows PowerShell.
- Search, Desktop/Store filters, application counts and metadata views.
- Open reported installation folder and copy app details.
- Clear upcoming-feature previews for Forced Uninstall, Batch, Hunter Mode, Backups and Leftover Scanning.

IMPORTANT SAFETY NOTE
v0.1.0 is an INVENTORY-ONLY preview. It does not uninstall applications, delete files, remove Registry keys, scan or clean leftovers. The uninstall action is intentionally disabled until the verified uninstall engine is released.

SYSTEM REQUIREMENTS
Windows 10/11 x64. Self-contained .NET 10 distribution; no account or paid service required.

TESTING STATUS
Source is prepared. Real Windows compilation and runtime testing must be verified through GitHub Actions and a Windows PC/VM before describing this as stable.
