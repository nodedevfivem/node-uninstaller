# Branding: NODE Uninstaller

The user-supplied official red/cyan NODE Uninstaller logo is integrated in the app:

- `src/NODE.Uninstaller/Assets/NODE-Uninstaller-Official-Logo.png`: preserved high-resolution logo, transparent-background asset.
- `src/NODE.Uninstaller/Assets/NODE-Uninstaller-UI.png`: UI-scaled transparent version.
- `src/NODE.Uninstaller/Assets/NODE-Uninstaller.ico`: Windows executable and installer icon.

Visual system: deep midnight navy, cyan highlights, red danger accents, dark menus, and rounded cards. The application shows a clearly labeled *preview* of planned modules instead of displaying fake destructive functionality.

Avoid displaying the complete large logo at very small sizes: use the app icon for the title bar and the high-resolution image for About / splash views in future versions.
