# START HERE — NODE Uninstaller v0.1.0

1. This is a complete source-only Windows foundation candidate, NOT an executable.
2. Open `README.md` for the current implemented features and GitHub Actions instructions.
3. Upload this complete project to your GitHub `NODE-Uninstaller` repository.
4. In Actions, run **Build NODE Uninstaller (Windows)**.
5. Download the produced `NODE-Uninstaller-v0.1.0-Windows-Build` artifact.
6. Inside, use `NODE-Uninstaller-Setup-v0.1.0.exe`, or unzip the portable package and launch `NODE.Uninstaller.exe`.
7. Test the app detection, searching, store packages, opening folder, and copying metadata on a Windows VM or test machine.

Important: v0.1.0 is **READ-ONLY INVENTORY**. It cannot uninstall or delete anything. Later versions are needed for those features.

Not yet independently built or run on Windows. GitHub Actions results and local testing determine whether additional build fixes are required.
